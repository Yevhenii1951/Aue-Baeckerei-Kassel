# ABE-007 Cafe Content

Implements: FR-12

## Goal

Create a visible cafe section/page with coffee, sweets, seating copy, and
replaceable image slots for future interior photos.

## Verification

Scenario: GIVEN a visitor is looking for a place to drink coffee, WHEN they open
Cafe content, THEN they see opening-hours context, drink/sweets pairings, and a
clear visit CTA.
